# kb_count 202610201405

Windows x64 便携版，基于 Rust、Slint、Windows Raw Input 和 SQLite。下载 `kb_count.exe`，放入具有读写权限的文件夹即可使用；启动后默认进入系统托盘。

## 已实现

- 全局键盘、鼠标按钮和滚轮统计，过滤键盘长按重复，按应用及本地日期保存聚合结果。
- 今日、昨日、日历及快捷日期查询；输入趋势支持日、周、月、年和前后周期切换。
- 应用排行、搜索、详情、物理键位热力图，以及浅色／深色主题和小窗口布局适配。
- Detailed、Totals Only、Excluded 三种应用策略；支持应用选择、搜索、策略筛选和恢复默认策略，保留历史数据。
- 关闭窗口时可选择后台运行或退出，并可在设置中修改是否记住该行为。
- CSV 日期范围快捷选择、后台导出、进度及取消操作。
- 单实例、托盘暂停／恢复、批量数据库写入和退出前保存。

## 数据与升级

- `stats.db`、`config.toml` 及可选日志均保存在 EXE 所在目录。此发布不包含个人统计库或配置。
- 只保存按日／小时的聚合统计，不保存输入文字、按键顺序、逐次按键时间戳或鼠标轨迹。
- 更新前从托盘正常退出旧版本，再替换 EXE；建议先备份整个程序目录。整个目录可复制迁移。
- 附件 `SHA256SUMS.txt` 可用于核对可执行文件完整性。

- 发布前通过 `cargo fmt --all -- --check`、`cargo check --locked --offline`、`cargo clippy --all-targets --locked --offline -- -D warnings`、`cargo test --locked --offline` 和 `cargo build --release --locked --offline`。
