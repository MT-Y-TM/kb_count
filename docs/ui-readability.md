# 界面可读性与应用图标

## 字体层级

使用 Microsoft YaHei UI 和 Slint 逻辑像素，跟随 Windows DPI 缩放；不按物理分辨率再次缩小字体。小窗口优先减少留白和辅助文案。

| 用途 | 逻辑字号 | 125% 对应物理尺寸 | 150% 对应物理尺寸 |
|---|---:|---:|---:|
| 页面标题 | 22–25px | 27.5–31.25px | 33–37.5px |
| 主要计数 | 26–30px | 32.5–37.5px | 39–45px |
| 导航 | 14px | 17.5px | 21px |
| 应用名称、数值和分类列表 | 13px | 16.25px | 19.5px |
| 路径、表头、占比、说明 | 12px | 15px | 18px |
| 页脚及装饰说明 | 11px | 13.75px | 16.5px |

排行行高为普通窗口 72px、窄窗口 68px。名称、路径和占比分三行排列；长名称和路径省略显示，完整路径在详情中换行展示。热力图键帽标签 11px、次数 10px，完整次数还可通过 12px 悬停提示和 13px 分类列表查看。

## 图标

从本地可执行文件使用 Windows [SHDefExtractIconW](https://learn.microsoft.com/zh-cn/windows/win32/api/shlobj_core/nf-shlobj_core-shdefextracticonw) 提取 64×64 图标，在排行显示为 32×32 逻辑像素，详情显示为 40×40。资源不足时由 Windows 选择可用分辨率，无法保证每个第三方程序都有高分辨率源图标。

通过黑、白背景合成恢复透明度，兼容带 Alpha 和旧式掩码图标；原生图标和 GDI 对象在读取后释放。图标提取不执行 EXE，不查询窗口标题，不调用在线图标服务；UNC 和映射网络驱动器保留备用标识。图标以应用完整路径为身份，仅在内存缓存，目录迁移后不会把旧图标归属给不同路径。

只在面板可见时请求图标，使用一个工作线程、最多 32 项待处理请求和 128 项内存缓存。当前详情优先，然后加载筛选结果前 127 项。大量历史应用可以搜索或进入详情加载；关闭面板后不触发新请求，已提交请求仅完成缓存，不更新隐藏页面。

## 验证范围

离线测试使用 Slint 软件渲染器及内存 SQLite，覆盖四页深浅主题、820×440 最小客户区，以及 1280×720 物理客户区的 100%、125%、150% 缩放。真实图标样例来自 Windows PowerShell、资源管理器和记事本；统计计数均为测试数据，不读取个人统计库，也不启动这些程序。

自动检查原生图标透明度、缓存容量、异步提取到排行的更新、搜索后的图标保留、详情复用及常用操作点击。预览位于 `target/ui-review/icons-{100,125,150}-{0,2}.bmp`，可通过 README 的命令重新生成。

仍需实机验证：不同显示器的字体抗锯齿、Windows 单独文本大小设置、跨屏 DPI 切换、显示器工作区边界以及低分辨率第三方源图标的主观清晰度。离线缩放通过不代表这些场景已完成验证。
