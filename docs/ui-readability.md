## 图标

从本地可执行文件使用 Windows [SHDefExtractIconW](https://learn.microsoft.com/zh-cn/windows/win32/api/shlobj_core/nf-shlobj_core-shdefextracticonw) 提取 96×96 图标，在排行显示为 32×32 逻辑像素，详情显示为 40×40。在 200% 缩放下分别占 64×64 和 80×80 物理像素，图像源无需放大；满缓存的原始 RGBA 数据约 4.5 MiB，渲染器及对象额外开销另计。资源不足时由 Windows 选择可用分辨率，无法保证每个第三方程序都有高分辨率源图标。

kb_count 标识为蓝底白色 K，字形使用矢量多边形，不依赖字体。`assets/kb_count.svg` 为源文件，`tools/generate_icon.py` 生成 16/20/24/28/32/40/48/56/64/96/128/256px ICO，包含 175% 对应的 28px 小图标及 56px 大图标；窗口和侧栏内嵌 SVG，Windows SDK 资源编译器把 ICO 与版本信息嵌入 EXE。托盘按系统小图标尺寸从模块资源加载并保持原生句柄，释放时先移除托盘图标。

通过黑、白背景合成恢复透明度，兼容带 Alpha 和旧式掩码图标；原生图标和 GDI 对象在读取后释放。图标提取不执行 EXE，不查询窗口标题，不调用在线图标服务；UNC 和映射网络驱动器保留备用标识。图标以应用完整路径为身份，仅在内存缓存，目录迁移后不会把旧图标归属给不同路径。

只在面板可见时请求图标，使用一个工作线程、最多 32 项待处理请求和 128 项内存缓存。当前详情优先，然后加载筛选结果前 127 项。大量历史应用可以搜索或进入详情加载；关闭面板后不触发新请求，已提交请求仅完成缓存，不更新隐藏页面。
