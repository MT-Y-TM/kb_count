# 界面可读性与应用图标

## 字体层级

使用 Microsoft YaHei UI 和 Slint 逻辑像素，跟随 Windows DPI 缩放；不按物理分辨率再次缩小字体。小窗口优先减少留白和辅助文案。

| 用途 | 逻辑字号 | 125% 对应物理尺寸 | 150% 对应物理尺寸 |
|---|---:|---:|---:|
| 页面标题 | 22–25px | 27.5–31.25px | 33–37.5px |
| 主要计数 | 26–30px | 32.5–37.5px | 39–45px |
| 导航 | 14px | 17.5px | 21px |
| 应用名称、数值和分类列表 | 13px | 16.25px | 19.5px |
| 路径、表头、占比、说明 | 12px | 15px | 18px |
| 页脚及装饰说明 | 11px | 13.75px | 16.5px |

排行行高为普通窗口 72px、窄窗口 68px。名称、路径和占比分三行排列；长名称和路径省略显示，完整路径在详情中换行展示。热力图键帽标签 11px、次数 10px，完整次数还可通过 12px 悬停提示和 13px 分类列表查看。

## 图标

从本地可执行文件使用 Windows [SHDefExtractIconW](https://learn.microsoft.com/zh-cn/windows/win32/api/shlobj_core/nf-shlobj_core-shdefextracticonw) 提取 96×96 图标，在排行显示为 32×32 逻辑像素，详情显示为 40×40。在 200% 缩放下分别占 64×64 和 80×80 物理像素，图像源无需放大；满缓存的原始 RGBA 数据约 4.5 MiB，渲染器及对象额外开销另计。资源不足时由 Windows 选择可用分辨率，无法保证每个第三方程序都有高分辨率源图标。

kb_count 标识为蓝底白色 K，字形使用矢量多边形，不依赖字体。`assets/kb_count.svg` 为源文件，`tools/generate_icon.py` 生成 16/20/24/28/32/40/48/56/64/96/128/256px ICO，包含 175% 对应的 28px 小图标及 56px 大图标；窗口和侧栏内嵌 SVG，Windows SDK 资源编译器把 ICO 与版本信息嵌入 EXE。托盘按系统小图标尺寸从模块资源加载并保持原生句柄，释放时先移除托盘图标。

通过黑、白背景合成恢复透明度，兼容带 Alpha 和旧式掩码图标；原生图标和 GDI 对象在读取后释放。图标提取不执行 EXE，不查询窗口标题，不调用在线图标服务；UNC 和映射网络驱动器保留备用标识。图标以应用完整路径为身份，仅在内存缓存，目录迁移后不会把旧图标归属给不同路径。

只在面板可见时请求图标，使用一个工作线程、最多 32 项待处理请求和 128 项内存缓存。当前详情优先，然后加载筛选结果前 127 项。大量历史应用可以搜索或进入详情加载；关闭面板后不触发新请求，已提交请求仅完成缓存，不更新隐藏页面。

## 验证范围

查询与 CSV 起止日期共用 352×392 逻辑像素的中文日历，820×440 最小窗口上下各保留 24px。年月导航、快捷日期和取消使用 Slint 按钮；42 个日期格按周一到周日排列，选中日期为蓝底白字，今天额外描边，相邻月份使用弱化文字。日期格支持方向键与回车，Page Up / Page Down 翻月，Esc 取消；Tab 在日期间移动，避免焦点离开日历。日历为现有窗口内的覆盖层，不创建另一个原生窗口；仅打开、翻月和移动选择时重算日期模型。离线回归覆盖所有缩放档的实际点选、重开后 Esc、键盘跨月、今天／昨天、查询自动刷新，以及 CSV 起止日期独立回填；日期单元测试覆盖闰年、月底、跨年和非法输入。

相邻月份文字对比度为浅色 4.75:1、深色 4.70:1；深色选中日期白字对比度 4.56:1。预览为 `calendar-{100,125,150,175,200,minimum}.bmp`、`calendar-minimum-light.bmp` 和 `calendar-export-{100,125,150,175,200,minimum}.bmp`。这些预览使用样例数据；测试不会调用真实 CSV 保存对话框。

2026-10-16 日期选择阶段验证：`cargo fmt --all -- --check`、`cargo check --locked --offline`、`cargo clippy --all-targets --locked --offline -- -D warnings` 均通过；开启离线预览后的完整 `cargo test --locked --offline` 为 35 项通过、0 失败，测试耗时 64.66 秒。上述为功能回归时长，不是后台资源占用测量。

日期选择阶段的 `cargo build --release --locked --offline` 成功，优化编译耗时 5 分 29 秒；产物 `target/release/kb_count.exe` 为 14,737,408 字节。`tools/verify_release.py` 确认 x64 GUI 子系统、十二种内嵌图标尺寸和版本资源完整。

长页面的横向滚动限定在键盘区域，分类表与页面保持同宽，避免最小窗口下鼠标次数被裁切。垂直滚动支持从键盘区域传递到整页，滚动后页脚提供“回到顶部”。右侧特殊键的悬停提示向左对齐，并给第一排提示保留顶部空间。

清空反馈位于本地存储区域，固定清空按钮宽度并预留提示行高；确认与取消不改变目标位置或上方策略区域的高度。关闭面板与离开设置会取消待确认操作。

离线测试使用 Slint 软件渲染器及内存 SQLite，覆盖四页深浅主题、820×440 最小客户区，以及 100%、125%、150%（1280×720 物理客户区）、175%（1680×945）和 200%（1920×1080）缩放。较高缩放采用更大的物理客户区，以满足 820×440 逻辑像素最小尺寸；不代表 1280×720 屏幕能在 200% 下容纳该窗口。真实图标样例来自 Windows PowerShell、资源管理器和记事本；统计计数均为测试数据，不读取个人统计库，也不启动这些程序。

自动检查原生图标透明度、缓存容量、异步提取到排行的更新、搜索后的图标保留、详情复用及常用操作点击；通过 Win32 加载测试 EXE 内嵌图标资源并核对十二种尺寸。预览位于 `target/ui-review/icons-{100,125,150,175,200}-{0,2}.bmp`，200% 暂停状态的深浅主题为 `paused-{dark,light}-200.bmp`，可通过 README 的命令重新生成。

各缩放档及 820×440 最小窗口还回归真实 Slint 滚动/点击事件：滚动至各长页底部、键盘横向滚动隔离、从键盘区域垂直滚动、应用查询、进入策略管理、CSV 导出按钮、同一位置的二次确认、取消、关闭面板取消以及返回顶部。清空检查使用生产代码的确认状态函数，确认后只累计测试回调次数，不执行真实数据清理或文件导出。相关预览为 `scroll-{100,125,150,175,200,minimum}-{1,2,3}-bottom.bmp` 和 `clear-{100,125,150,175,200,minimum}-confirm.bmp`。

仍需实机验证：不同显示器的字体抗锯齿、Windows 单独文本大小设置、跨屏 DPI 切换、显示器工作区边界以及低分辨率第三方源图标的主观清晰度。离线缩放通过不代表这些场景已完成验证。

## 2026-10-17：权限提示与小窗口总览

用户确认对强制管理员运行的游戏保留普通权限，将输入缺失明确列为采集限制。顶部显示“可能受限”，并说明“本次运行曾检测到管理员应用，相关输入可能未计入”；设置固定说明权限范围。通知跨线程通过容量为 1 的 channel 传递，面板隐藏时不更新 Slint；返回面板后仍保留本次运行的说明，不修改统计数值、暂停状态或应用策略。独立接收对照和证据边界见 [全屏游戏输入排查](fullscreen-input.md)。

本轮小屏预览发现提示挤占高度后，总览的排行底部可能不可访问。总览现在使用 Slint ScrollView；内容高度同时考虑布局最小高度与首选高度，保留排行的可用区域。高度足够时维持原布局，空间不足时可滚动到完整应用行及表格说明。总览也提供“回到顶部”；日期、暂停和页脚位于内容滚动区之外。页脚固定 32px，避免返回顶部按钮出现时改变可滚动高度。紧凑布局的提示高 36px，不引入新的动画或绘制线程。

权限提示的离线回归检查隐藏状态不消费通知、不改变数据或暂停状态、重复刷新仍保留提示；在 820×440 深浅主题中发送真实 Slint 滚轮与点击事件，验证总览可滚动、应用行可进入详情、回到顶部可点选。渲染预览使用显式测试数据，与真实用户统计无关。可单独生成本轮预览：

```powershell
$env:KB_COUNT_RENDER_UI = '1'
$env:KB_COUNT_CAPTURE_NOTICE_ONLY = '1'
cargo test --locked --offline ui_tests::refresh_preserves_ui_filters_and_privacy_state -- --exact
Remove-Item Env:KB_COUNT_RENDER_UI, Env:KB_COUNT_CAPTURE_NOTICE_ONLY
```

预览位于 `target/ui-review/capture-limited-{light,dark}.bmp`、`capture-limited-{light,dark}-bottom.bmp` 和 `capture-limited-settings-{light,dark}.bmp`。该快捷运行只检查本轮交互，不能替代正常完整测试；它不注册输入设备、不切换桌面前台，也不读取个人数据库。

最终完整 `cargo test --locked --offline`：56 项通过、0 失败，90.83 秒。单独预览回归 1 项通过，11.49 秒；检查了深浅主题下最小窗口的实际渲染。普通测试也先完成真实布局帧再发送滚轮及点击，不依赖开启截图才能通过。完整回归保留原有 100%、125%、150%、175%、200% 离线缩放及采集、数据库、隐私测试；真实跨显示器 DPI 与系统单独文本缩放仍属于前述实机验证范围。
